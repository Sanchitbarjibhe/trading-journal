# 📈 TradeJournal - Smart Trading Journal & Psychology Tracker

A minimalistic, high-performance Trading Journal designed for modern traders to log trades, upload charts, and analyze their trading psychology (FOMO, Greed, Patience) to eliminate mistakes and master risk management.

![Version](https://img.shields.io/badge/version-v1.0.0--beta-black?style=flat-for-the-badge)
![Tech Stack](https://img.shields.io/badge/tech--stack-Next.js%20%7C%20Tailwind%20CSS-blue?style=flat-for-the-badge)

---

## ✨ Features (v1.0.0 - MVP)

- **⚡ Clean Dark Minimal UI:** Designed specifically for traders to reduce cognitive load during fast-paced market hours.
- **📊 Detailed Trade Logging:** Easily capture Trade Date, Market Type (Crypto/Equities), Instrument (e.g., BTCUSD, INFY), Position Sizing, and precise Entry/Exit price points.
- **🧠 Psychology & Setup Tags:** Tag your emotions (*FOMO, Greed, Fear, Patience*) and structural setups (*Liquidity Sweep, Order Block*) to uncover institutional footprints and behavioral flaws.
- **📝 Reflection Notebook:** A dedicated rich-text area to write detailed trade notes, list out mistakes, and document lessons learned.
- **📸 Screenshot Drag & Drop:** Before-and-after chart screenshot uploads to keep a visual track of trade execution.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), Tailwind CSS
- **UI Components:** Shadcn UI / Radix Primitives
- **State Management / Forms:** React Hook Form + Zod (for clean validation)
- **Deployment & Hosting:** Vercel
